# Per-source timestamps in price history

The frontend accepts an optional `sourceTimestamps` array on each historical
price point:

```json
{
  "sources": ["chainlink", "redstone"],
  "sourceTimestamps": [
    { "source": "chainlink", "timestamp": 1693485595000 },
    { "source": "redstone", "timestamp": 1693485598000 }
  ]
}
```

The timestamp is the Unix time in milliseconds at which that source contributed
to the aggregate. The frontend does not infer or copy the aggregate timestamp
when this field is absent. It displays “Unavailable from API” for missing
contributors. A provided source timestamp more than 60 seconds behind the
aggregate's timestamp is labeled stale.

**Backend dependency:** the existing history response does not guarantee
`sourceTimestamps`. The API producer must preserve the original per-source
timestamps and return the optional field from both single-pair history and
batch-history responses. Until then, the UI's explicit unavailable state is
expected. No upstream values are generated by the frontend or test fixtures.
